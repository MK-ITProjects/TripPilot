About This Project

A college project recreating TripPilot's travel-planning experience with Python.

Project Overview

This is a full-stack travel planning platform built with Python + Django, demonstrating two core data-science skills: web scraping and machine learning. It lets users explore destinations, generate AI-assisted itineraries, predict tourist crowd levels, calculate trip budgets and chat with a travel assistant — all backed by real and simulated scraped data.

Web Scraping
  • Travel news — scraped from Wikipedia's "In the news" (BeautifulSoup + Requests)
  • Attraction descriptions — scraped from destination Wikipedia pages
  • Weather updates — fetched from the free Open-Meteo API
  • Hotel prices & local events — simulated sample data generators
Machine Learning
  • Crowd-level classification — Decision Tree & Random Forest
  • Trip cost estimation — Linear Regression
  • Destination segmentation — K-Means clustering
Tech Stack

Python, Django, HTML/CSS/JavaScript, Bootstrap, SQLite, BeautifulSoup, Requests, Pandas, NumPy, Scikit-learn.
